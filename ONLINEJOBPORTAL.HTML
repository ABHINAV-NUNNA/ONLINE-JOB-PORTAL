04
                            / SECURITY SCOPE

                        

                            Trust starts with an honest scope.

                        

                            The exported example supports public, read-only sample job search. It should not be
                            presented as a production hiring platform.

                    

                    

                        

                            What is included

                        

                            PostgreSQL-backed sample jobs, server-side query-length checks, same-origin frontend
                            requests, schema migration, and API tests.

                        

                            What still needs implementation

                        

                            Registration and login, profiles, saved jobs, applications, recruiter/admin permissions,
                            password hashing, authenticated session or token handling, CSRF controls, rate limiting, and
                            audit logging are not included. Do not collect passwords or claim these safeguards are
                            active.

                        example to hosted service.

                        server or database; download the ZIP and deploy those components separately.
